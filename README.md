# ربات جوین اجباری تلگرام

## نصب

```bash
pip install -r requirements.txt
```

## تنظیم اولیه

1. متغیرهای محیطی سرویس را تنظیم کنید (توکن‌ها و کلیدها را داخل فایل کد قرار ندهید):
   - `BOT_TOKEN` → توکن ربات از @BotFather
   - `SUPABASE_URL` و `SUPABASE_KEY` → اطلاعات پروژهٔ Supabase
   - `WEBHOOK_URL` (یا `RENDER_EXTERNAL_URL`) → نشانی عمومی سرویس
   - `CARD_NUMBER` و `CARD_HOLDER` → اطلاعات پرداخت
   - `ADMIN_IDS` → اختیاری؛ آیدی ادمین‌های اضافه، جداشده با کاما. دو ادمین فعلی در کد حفظ شده‌اند.
2. ربات را اجرا کنید:
   ```bash
   python bot.py
   ```
3. ربات را در گروه مورد نظر **ادمین** کنید (با دسترسی حذف پیام).
4. ربات را در کانال‌های جوین اجباری هم **ادمین** کنید (با دسترسی ساخت لینک دعوت در صورت نیاز).
5. در پیوی ربات دستور `/start` را بزنید تا پنل مدیریت باز شود.
6. از پنل: «تنظیم گروه» → یک پیام از گروه فوروارد کنید یا آیدی عددی گروه را بفرستید.
7. از پنل: «مدیریت کانال‌ها» → «افزودن کانال» → یک پیام از کانال فوروارد کنید، یا دستی به فرمت زیر بفرستید:
   ```
   @channel_username | https://t.me/channel_username
   ```

## ویرایش متن‌ها

از پنل مدیریت → «ویرایش متن‌ها» → متن هشدار یا متن تایید عضویت را ویرایش کنید.

متغیرهای قابل استفاده در متن‌ها:
- `{mention}`
- `منشن_کاربر`

هرکدام را در متن بگذارید، جای منشن کاربر قرار می‌گیرد. اگر هیچ‌کدام را نگذارید، منشن به‌صورت خودکار در ابتدای پیام اضافه می‌شود (چون تگ کردن کاربر الزامی است).

## نکته درباره رنگ دکمه‌ها

قابلیت رنگی‌کردن دکمه‌های شیشه‌ای (inline keyboard) از سمت کد ربات در API رسمی تلگرام برای بات‌ها وجود ندارد؛ این ویژگی صرفاً از سمت کلاینت/کاربر برای شخصی‌سازی ظاهریست و پارامتری در سطح Bot API برایش تعریف نشده، پس در کد قابل تحمیل نیست.

## محدودیت‌های اعمال‌شده طبق درخواست

- ربات فقط در یک گروه (تعیین‌شده توسط مالک) فعال است.
- فقط ادمین‌های تعریف‌شده در `ADMIN_IDS` به پنل مدیریت در پیوی دسترسی دارند.
- کانال‌ها قابل افزودن/حذف هستند.
- منشن کاربر در تمام پیام‌های هشدار/تایید اجباری و تضمین‌شده است.
- پیام کاربر غیرعضو حذف و پیام هشدار جایگزین می‌شود؛ با تایید عضویت، همان پیام ادیت می‌شود.

## آیتم نوع «ربات» (بدون نیاز به دیتابیس مشترک)

از پنل: «مدیریت آیتم‌ها» → «افزودن ربات» → یوزرنیم (`@id_bot`)، لینک (`https://t.me/id_bot`) یا لینک با پارامتر (`https://t.me/id_bot?start=ref123`) را بفرستید.

- دکمه‌ی ربات یک لینک مستقیم است و پیوی ربات مقصد با دکمه‌ی Start باز می‌شود.
- ربات بررسی واقعی ندارد؛ زدن دکمه‌ی «بررسی عضویت» ورود کاربر به همه‌ی ربات‌ها را تایید می‌کند.
- نیازی به تغییر در ربات مقصد یا دیتابیس مشترک نیست.
- کانال‌ها و گروه‌ها همچنان با `getChatMember` واقعی بررسی می‌شوند.
- در مدیریت هر ربات، دکمه‌ی «کاربران عضو شده» تعداد کاربران تاییدشده را نشان می‌دهد.

## رفتار پیام هشدار

- فقط مواردی که کاربر هنوز در آن‌ها عضو نیست نمایش داده می‌شود؛ با «بررسی عضویت» دکمه‌ی مواردی که عضو شده حذف می‌شود.
- لیست موارد باقی‌مانده داخل نقل قول (blockquote) چاپ می‌شود و متن‌های پیش‌فرض بولد هستند.
- متن‌هایی که مالک در پیوی تنظیم می‌کند با تمام قالب‌بندی‌اش ذخیره و همان‌طور ارسال می‌شود.
- دکمه‌های «بررسی عضویت» فقط برای کاربرِ هدفِ پیام فعال هستند.

## سرعت حذف پیام‌ها

- هر پیام غیرعضو بلافاصله و مستقل حذف می‌شود (ده پیام هم‌زمان = ده حذف هم‌زمان) و بعد از حذف، فقط **یک** هشدار برای هر کاربر ارسال می‌شود.
- حذف با تلاش مجدد روی محدودیت نرخ تلگرام (RetryAfter) و خطای شبکه انجام می‌شود.
- تنظیمات، آیتم‌ها و متن‌ها ۱۵ ثانیه کش می‌شوند (با هر تغییر ادمین بلافاصله پاک می‌شود) و بررسی عضویت چند پیام هم‌زمان یک کاربر فقط یک بار انجام می‌شود.

## تایید خودکار عضویت

- وقتی کاربر در کانال/گروه جوین اجباری عضو می‌شود، پیام هشدارش خودکار ادیت می‌شود: دکمه‌ی همان مورد حذف می‌شود و وقتی همه کامل شد متن «تایید عضویت» جایگزین می‌شود. نیازی به زدن «بررسی عضویت» نیست.
- ورود به ربات‌ها هم وقتی همه‌ی کانال/گروه‌ها کامل شد خودکار تایید می‌شود.
- **شرط:** ربات باید در همه‌ی کانال‌ها/گروه‌های جوین اجباری **ادمین** باشد تا تلگرام رویداد `chat_member` را بفرستد.
- دکمه‌ی «بررسی عضویت» به‌عنوان جایگزین باقی مانده (مثلاً برای کاربری که از قبل عضو کانال‌ها بوده و فقط ربات‌ها مانده).
- دکمه‌های پیام هشدار در گروه رنگ ندارند؛ فقط دکمه‌های پنل مدیریت رنگی هستند.

## تنظیم زمان آیتم‌ها (دکمه‌های «تنظیم هم اکنون» و «تنظیم زمان»)

بعد از افزودن هر کانال/گروه/ربات در پنل، دو دکمه می‌آید (این دو دکمه در صفحه‌ی مدیریت هر آیتم هم هست):

- **⚡ تنظیم هم اکنون:** آیتم همین لحظه فعال می‌شود و محدودیت زمانی ندارد.
- **⏰ تنظیم زمان:** مدت فعال بودن را می‌فرستید (`30m` دقیقه، `12h` ساعت، `7d` روز، `90 دقیقه`، `2 روز`؛ فقط عدد = ساعت). بعد از پایان مدت، آیتم خودکار از جوین اجباری کنار می‌رود (حذف نمی‌شود؛ در لیست پنل با ⛔️ دیده می‌شود و می‌توانید دوباره زمان بدهید یا حذفش کنید).

**فقط یک‌بار در Supabase اجرا کنید:**

```sql
alter table channels add column if not exists expires_at timestamptz;
```

## تعرفه‌ی ممبر (سقف تعداد ورودی)

بعد از افزودن هر کانال/گروه/ربات، ربات **تعداد ممبر مورد نیاز** را از شما می‌پرسد:

- **عدد (مثلاً `200`):** وقتی همین تعداد کاربر جدید در آن مورد عضو شدند، آن مورد **خودکار و برای همیشه** از جوین اجباری برداشته می‌شود (در لیست پنل با ⛔️ دیده می‌شود).
- **`0`:** نامحدود؛ تا وقتی دستی حذف یا زمان‌بندی نشود فعال می‌ماند.

نکات:

- شمارش از لحظه‌ی ثبت تعرفه شروع می‌شود: تعداد ورودی = تعداد فعلی اعضا − تعداد اعضا هنگام ثبت تعرفه.
- بعد از تکمیل، خروج بعضی اعضا باعث فعال‌شدن دوباره‌ی آیتم نمی‌شود.
- هر زمان از «مدیریت آیتم‌ها» ← انتخاب آیتم ← **🎯 تعرفه‌ی ممبر** می‌توانید عدد جدید ثبت کنید (شمارش از نو شروع می‌شود و آیتمِ تکمیل‌شده دوباره فعال می‌شود).
- در لیست آیتم‌ها و صفحه‌ی مدیریت، پیشرفت به شکل `۳۷ / ۲۰۰` نمایش داده می‌شود.
- با هر ورود جدید به کانال/گروه (در صورت ادمین بودن ربات) تعرفه بلافاصله بررسی می‌شود؛ در غیر این صورت حداکثر هر ۳ ثانیه یک‌بار هنگام پیام‌های گروه.
- برای آیتم نوع «ربات»، تعداد استارت‌های تاییدشده شمرده می‌شود.

**فقط یک‌بار در Supabase اجرا کنید:**

```sql
alter table channels add column if not exists member_limit bigint;
alter table channels add column if not exists quota_done boolean not null default false;
```

## فروش جوین اجباری (پنل خرید کاربران)

هر کاربرِ غیرادمین که در پیوی ربات `/start` بزند، پنل خرید را می‌بیند (ادمین‌ها برای تست از `/buy` استفاده کنند):

1. انتخاب نوع: **کانال / گروه / ربات**
2. ارسال لینک، یوزرنیم، آیدی عددی یا فوروارد یک پیام (برای کانال/گروه، ربات باید **ادمین** باشد؛ بررسی خودکار انجام می‌شود)
3. انتخاب تعداد ممبر (دکمه‌ها یا عدد دلخواه؛ `0` = نامحدود)
4. نمایش خلاصه و قیمت: هر ممبر ۵۰۰ تومان (هر ۱۰۰ ممبر ۵۰,۰۰۰)، نامحدود ۱۰۰,۰۰۰ تومان
5. ارسال شماره کارت (قابل کپی با کلیک) و دریافت **عکس فیش**
6. ربات فیش را همراه مشخصات سفارش برای همه‌ی ادمین‌ها می‌فرستد با دکمه‌های **✅ تایید و ورود به صف** / **❌ رد فیش**
7. با تایید، کاربر پیام می‌گیرد و آیتم وارد **صف** می‌شود؛ جایگاه او اعلام می‌شود. هر وقت نوبتش شد (جوین اجباری فعال شد) و هر وقت تعرفه‌اش کامل شد، خودکار به کاربر اطلاع داده می‌شود.

تعرفه‌های جوین اجباری و ظرفیت صف فعلی طبق تنظیمات فروش باقی می‌مانند. شماره کارت و نام دارنده از متغیرهای محیطی `CARD_NUMBER` و `CARD_HOLDER` خوانده می‌شوند.

### صف
- هر آیتمِ خریداری‌شده با تایید ادمین در صف (`queued`) قرار می‌گیرد و تا نوبتش نرسیده جوین اجباری نیست.
- **ظرفیت هم‌زمان صف** از پنل ادمین («🛒 ظرفیت هم‌زمان صف فروش») تعیین می‌شود: چند آیتم خریداری‌شده هم‌زمان فعال باشند (پیش‌فرض ۱؛ `0` = بدون صف).
- ورود به جوین اجباری به‌ترتیب تایید (FIFO) است؛ با پایان تعرفه یا زمان، نفر بعدی خودکار فعال می‌شود (بررسی هر ۲۰ ثانیه).
- شمارش ممبرها از لحظه‌ی **فعال‌شدن** آیتم شروع می‌شود، نه لحظه‌ی خرید.
- آیتم‌های دستیِ ادمین (بدون سفارش) مستقل از صف و همیشه فوراً فعال‌اند.
- ادمین می‌تواند آیتمِ داخل صف را از صفحه‌ی مدیریتش با «⚡ تنظیم هم اکنون» زودتر فعال کند (⏳ در لیست = در صف).

**فقط یک‌بار در Supabase اجرا کنید:**

```sql
alter table channels add column if not exists queued boolean not null default false;
alter table channels add column if not exists order_id bigint;

create table if not exists orders (
    id bigint generated always as identity primary key,
    user_id bigint not null,
    user_name text,
    user_username text,
    kind text not null,
    chat_id text not null,
    title text not null,
    invite_link text not null,
    member_limit bigint not null default 0,
    price bigint not null,
    status text not null default 'awaiting_receipt',
    item_id bigint,
    receipt_file_id text,
    receipt_type text,
    created_at timestamptz not null default now()
);
```

## خدمات تلگرامی

از پنل خرید می‌توان سفارش **ویو، ممبر، ری‌اکشن، استارت ربات و کامنت** ثبت کرد. سفارش استارت ربات تعداد استارت درخواستی و لینک رفرال/دعوت ربات مقصد را می‌گیرد؛ تعرفهٔ اولیهٔ آن هر استارت ۵۰۰ تومان است و مالک می‌تواند آن را در پنل تغییر دهد. ویو، ممبر و ری‌اکشن حالت تکی و گروهی دارند؛ گروهی هزینه‌اش این‌طور محاسبه می‌شود:

`تعداد × قیمت هر واحد + تعداد روز × هزینهٔ روزانه`

تعرفه‌های اولیهٔ نمونه برای خدمات دیگر هر واحد ۱٬۰۰۰ تومان و هزینهٔ روزانه ۲۰٬۰۰۰ تومان است. مالک از پنل «خدمات تلگرامی و تعرفه‌ها» می‌تواند برای هر خدمت قیمت هر واحد و (برای خدمات گروهی) هزینهٔ روزانه را تغییر دهد. کاربر لینک هدف و تعداد را وارد می‌کند، خلاصه و مبلغ را می‌بیند، فیش را می‌فرستد و ادمین پرداخت را تایید یا رد می‌کند. تایید ادمین در این نسخه فقط تایید پرداخت است؛ اجرای سفارش با سشن‌ها خودکار نشده و باید توسط ادمین هماهنگ/انجام شود. برای شمارش واقعی استارت‌ها، خود ربات مقصد باید شروع کاربران را ثبت و گزارش کند؛ این ربات به‌تنهایی نمی‌تواند استارت‌شدن ربات دیگری را تایید کند.

### مهاجرت Supabase خدمات و سشن‌ها

این SQL را یک‌بار در Supabase اجرا کنید:

```sql
create table if not exists telegram_service_orders (
    id bigint generated always as identity primary key,
    user_id bigint not null,
    user_name text,
    user_username text,
    service_kind text not null,
    mode text not null,
    quantity bigint not null,
    target_url text not null,
    duration_days integer not null default 0,
    unit_rate bigint not null,
    daily_rate bigint not null default 0,
    price bigint not null,
    status text not null default 'awaiting_receipt',
    receipt_file_id text,
    receipt_type text,
    created_at timestamptz not null default now(),
    reviewed_at timestamptz
);

create index if not exists idx_tg_service_orders_user_status_id
    on telegram_service_orders (user_id, status, id desc);

create table if not exists telegram_service_sessions (
    id bigint generated always as identity primary key,
    label text not null,
    session_ciphertext text not null,
    is_active boolean not null default true,
    created_at timestamptz not null default now()
);
```

### مدیریت سشن اکانت‌ها

برای افزودن، فعال/غیرفعال‌کردن یا حذف سشن از پنل مالک → «مدیریت سشن اکانت‌ها» استفاده کنید. سشن یک دسترسی کامل به حساب تلگرام است: فقط حساب‌هایی را اضافه کنید که مالکشان هستید. پیام ورودی سشن بلافاصله حذف می‌شود و مقدار ذخیره‌شده با Fernet رمزگذاری می‌شود؛ مقدار رمزگشایی‌شده در پنل یا گزارش‌ها نشان داده نمی‌شود.

پیش از افزودن سشن، یک‌بار کلید Fernet بسازید:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

مقدار خروجی را به‌عنوان متغیر محیطی محرمانهٔ `TELEGRAM_SESSION_ENCRYPTION_KEY` تنظیم کنید و آن را در چت یا مخزن کد قرار ندهید. اگر این کلید گم شود، سشن‌های ذخیره‌شده قابل رمزگشایی نیستند.
